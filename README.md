# Artificial Intelligence Laboratory Tasks (Fall 2025)

A curated collection of foundational Artificial Intelligence algorithms, problem-solving agents, search heuristics, and practical programming exercises implemented in Python.

## Course Modules & Laboratory Directory

| Module | Core Concept | Language / Tools | Description |
| :--- | :--- | :--- | :--- |
| **Lab 1** | Game State Logic & Utilities | Python | Implementation of classic Tic-Tac-Toe game mechanics and an interactive To-Do task management application. |
| **Lab 2 Tasks** | Algorithmic Problem Solving | Python | Logic puzzles and control-flow implementations including FizzBuzz and a structured Movie catalog program. |
| **Task 3** | Agent Architectures | Python | Memory-Based Reflex Agent utilizing persistent internal state (`memory.txt`) to guide perception-action cycles. |
| **Task 4** | Problem-Solving Agents | Python | Goal-oriented problem-solving agent implementations with structured state representations. |
| **Lab 5** | Uninformed Search | Python | Tree and graph traversal using Depth-First Search (DFS) exploring search spaces. |
| **Lab 6** | Search Heuristics | Python | Multi-stage pathfinding and constraint satisfaction exercises. |
| **Task 7** | Applied AI Notebook | Python, Jupyter | Interactive notebook evaluating algorithm performance on sample state topologies. |
| **Lab 8** | Analytical Notebook | Python, Jupyter | Algorithmic analysis and computational complexity verification. |
